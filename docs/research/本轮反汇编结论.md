# 本轮反汇编结论（dev2 实测，供行为还原对照表引用）

> 全部来自 `原始文件/解包产物/mine2000.EXE` 的字节级验证，VA = 0x401000 + 文件偏移 - 0x1000。

## 1. 状态字段 `+0x190`：1=未开始 2=游戏中 3=胜利 4=失败

| VA | 写入 | 语义 | 上下文 |
|---|---|---|---|
| `0x401eb8` | 1 | 未开始 | 重置：清盘 → `+0xc1a0=0` → `timeGetTime()` → `+0xc1a4` |
| `0x4026fd` `0x40275d` `0x4027c0` `0x402820` `0x402880` | 1 | 未开始 | 5 个难度各自的初始化函数 |
| `0x40453b` | 2 | 游戏中 | 首次左键按下后 |
| `0x40252d` | 3 | 胜利 | 判定通关；同时写 `+0xc1a0` 并与高分榜比较 |
| `0x402940` | 4 | 失败 | 踩雷后；同时写 `+0xc1a0` |

计时器取值函数 `0x401c30` 按同一字段分派（跳转表 `0x401c70`）：
- 状态 1 → `0x401c6c`：`xor eax,eax; ret` → **返回 0**
- 状态 2 → `0x401c46`：`timeGetTime()` 差值 `* 0x51EB851F >> 37` = **毫秒差 / 100**
- 状态 3 / 4 → `0x401c64`：返回 `+0xc1a0`（冻结的最终用时）

**推论**：计时基准点是**关卡初始化时刻**（`+0xc1a4`），而非首次点击；未开始时显示恒为 0。

## 2. 表情 = 状态 × 鼠标（5 张脸全部可达）

表情跳转表 `0x403a1c`：`1→0x40388e`、`2→0x40388e`（未开始与游戏中**同一分支**）、`3→0x40391f`、`4→0x403978`。
绘制源 x（区域 C，26px 步进）：

| 条件 | 源 x | 槽位 |
|---|---|---|
| 状态 1/2，鼠标未按下 | `0x00` | 0 正常微笑 |
| 状态 1/2，鼠标在棋盘上按下 | `0x4E` | 3 惊讶（O 嘴） |
| 鼠标不在棋盘内（`+0x88`/`+0x8C` 均为 `-2`） | `0x68` | 4 备用正常脸 |
| 状态 3 胜利 | `0x1A` | 1 墨镜 |
| 状态 4 失败 | `0x34` | 2 X 眼 |

## 3. 计分单位 = 1/100 秒（百分秒）

- 计时器返回毫秒差 / 100 → 单位 **0.01 秒**。
- 计时显示上限 `cmp ecx, 0x1869F`（99999）→ 99999 × 0.01s = 999.99 秒。
- 高分榜对话框格式串 **`.rdata` 0x408F60 = `"%d.%d秒"`**（CP932），`0x408F68 = `"%d位にランクイン！！"`。
- 分隔符用法见 `0x401F32`：`idiv 0xA` 后 `push edx / push eax`（商的整数部分在前）。
- 内存高分榜布局：每难度 `0x3C`(60) 字节 = 5 条 × 12 字节（名字 4B + 分数 4B + 填充 4B），名字指针基址 `+0x58`，分数 `+0x5C`（`0x402630` / `0x40264E`）。

## 4. `.m2k` 记录（`0x402CB0` 读 / `0x402EE7` 写）

`[1 字节名字长度][Shift-JIS 名字][4 字节小端分数]`，共 25 条 = 5 难度 × 5 名。
默认档每条为 `08 | 96 BC 91 4F 82 C8 82 B5 | 9F 86 01 00`：
- 名字 = Shift-JIS「名前なし」（4 字符 8 字节）
- 分数 = `0x0001869F` = **99999**（与计时显示上限 `0x1869F` 同值 → 「无成绩」哨兵）

## 5. 失败时的棋盘揭示

图集区域 A 第 1 行含两个专用图块：
- `A1 c3` = 地雷 + 红底高亮（**刚踩中的那颗**）
- `A1 c4` = 地雷 + 红色 X（**旗插错的格子**，Windows 扫雷同款表现）

→ 原版在失败时揭示全部地雷，并对插错的旗画 X。

## 6. 其他

- 计时基点写入：`0x401ECC`（重置）与 `0x402894`（难度初始化）均调用 `timeGetTime()` 存入 `+0xC1A4`。
- 原版无音效（仅 `WINMM.timeGetTime` 计时）。
- `0x4048A3` 写 `+0x8C = -2`、`0x404AB6` 写 `+0x88 = 0` → 鼠标坐标用 `-2` 表示「在棋盘外」。
- `+0x90` 取值 1 / 3：鼠标按键状态（1=未按下，3=按下）。
