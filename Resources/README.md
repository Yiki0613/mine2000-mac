# 资源 / AppIcon.icns

应用图标。**不是找图或 AI 生成的**，而是用图集里的真实像素 + 矢量背景绘制出来的，
所以和游戏内的视觉 100% 一致。

## 设计

```
┌─────────────────────────┐
│  深蓝灰圆角背景           │   824×824，圆角 185（macOS 图标规范）
│  ┌───┬───┬───┐          │
│  │   │   │   │          │   3×3 网格 = 9 个「未翻开格」
│  ├───┼───┼───┤          │   每格 200px，间隙 28px
│  │   │ 🚩 │   │          │   中心格 = 红旗（放大 0.82 倍）
│  ├───┼───┼───┤          │   周围 8 格压暗 28%，让中心成为焦点
│  │   │   │   │          │
│  └───┴───┴───┘          │
└─────────────────────────┘
```

| 元素 | 来源 | 说明 |
|---|---|---|
| 格子 | 图集 `.coveredCell`（0,16） | 192 灰面 + 白高光 + 128 阴影，最近邻放大 |
| 红旗 | 图集 `.flag`（16,16）中心 10×10 | 同上，单独放大以突出 |
| 背景 | 矢量绘制 | 线性渐变 `#42474E` → `#12141A`，圆角 185 |
| 透明边距 | — | 四周 100px 全透明（占画布 37.5%） |

**为什么用图集像素而不是重绘**：这款 app 的卖点是「像素级还原原版」，
图标也应该用同一批像素，一眼就能对上是同一个游戏。矢量重绘会更"现代"，
但就和游戏内的观感脱节了。

## 尺寸

`iconutil` 标准的 10 个尺寸，全部从同一份绘制代码按目标尺寸**重新渲染**
（不是缩放 1024 的位图），所以小尺寸下矢量部分依然锐利：

```
16 / 32 / 64 / 128 / 256 / 512 / 1024（含 @2x）
```

> 16px 下九宫格的间隙不足 1px 会糊成马赛克，但中心红点仍可辨认 ——
> 这与绝大多数 app 在 16px 下的表现一致，Dock（48–64px）和 Finder（32px+）都清晰。

## 重新生成

```bash
bash build.sh icon     # 从 Sources/Mine2000/Resources/tiles_144x81.bmp 重新渲染 Resources/AppIcon.icns
bash build.sh app      # 打包时自动把 icns 塞进 .app/Contents/Resources/
```

生成脚本：`工具/图标生成.swift`

## 调试时踩的两个坑

1. **旗子上下颠倒** —— DIB 行序是自下而上，我又翻转了一次 CGContext，
   两次翻转互相抵消。正解：`atlasTile` 里按「左上原点」取行，
   绘制交给 `NSImage.draw(in:)`，由 AppKit 处理方向，**不要手动翻 context**。
2. **每格都投一次影，格子之间脏** —— `setShadow` 在循环外设置时，
   每次 `draw` 都会投一次。要么只给整体投一层，要么干脆不投
   （图集格子自带高光/阴影，已经够立体）。
